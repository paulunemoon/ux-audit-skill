Run the `ux-audit` skill in **a11y** mode (SKILL.md §6).

Target: $ARGUMENTS

1. Run the audit gate (§0) — scope, platform, and evidence at minimum.
2. Load `references/accessibility.md` plus the relevant platform file
   (`platform-web.md` or `platform-mobile.md`).
3. Spend the effort where automated tooling can't reach: keyboard operability
   of custom controls, focus order and management, meaningful alt text,
   screen-reader flow, and whether the semantics describe the thing. If the user
   has axe or Lighthouse output, use it as a starting inventory, not as the
   audit.
4. Measure contrast with `scripts/contrast-check.py` — give the ratio, not an
   impression.

Key findings to their success criteria and level. State how each was tested.
**Make no conformance claim in either direction** — this is a sampled review.
